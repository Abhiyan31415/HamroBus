# Hamro Bus
Hamro Bus is a bus management system designed to help users easily access information about bus routes, fares, and schedules. It aims to simplify travel planning for commuters, providing them with up-to-date bus information in Nepal.

Features
-Route Finder: Search for bus routes based on your starting point and destination.
-Fare Information: Get detailed fare information for each bus route.
-Schedule Info: Access the daily schedules of buses for easy planning.
-Bus Stops: View a list of bus stops along each route.
-Real-Time Tracking: Track buses in real-time to estimate arrival times at bus stops.

Technologies Used
Frontend: HTML, CSS, JavaScript 
Backend: Node.js, Express
Database: MongoDB (for storing bus routes, fares, and schedules)
Usage
Once the app is running, you can:

Search for bus routes between any two locations.
Check the bus schedules and fare details.
Get information about the closest bus stops.
